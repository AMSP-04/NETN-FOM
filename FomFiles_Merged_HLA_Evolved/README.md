This folder contains the entire NETN-FOM merged and exported in HLA Evolved format.

The merged FOM-module contains all the NETN modules and the entire RPR_FOM_v2.0_1516-2010 FOM.

For this module to fully work, you must also load the NETN-MIM. 
This custom MIM is the standrad MIM but with the extension to HLAobjectRoot and HLAinteractionRoot made in NETN-BASE and NETN-TMR.
